# 规格：任务托盘 UI (task-tray-ui)

## 需求说明
前端应提供非阻断式的交互体验，允许用户在后台任务运行期间自由操作其他页面。

## UI 交互
1. **任务托盘**：在页面右下角或顶部导航栏显示一个任务状态图标。
2. **气泡通知**：
   - 任务启动时，显示一个进度气泡。
   - 任务成功时，显示绿色勾选并停留 3 秒。
   - 任务失败时，显示红色警告并允许用户点击查看错误日志。
3. **状态同步**：页面加载时，自动请求活跃任务列表以同步托盘状态。

## 验收标准
- [ ] 点击“添加机器人”后，页面不显示全屏遮罩，而是在侧边或托盘显示加载。
- [ ] 用户可以随时从“添加机器人”页面切换到“实时日志”页面而不打断任务。
- [ ] 托盘能够显示多个正在并行或排队执行的任务。

## Requirements (Visual Updates)

### Requirement: 增强型会话列表视觉呈现
会话列表 SHALL 采用复合视觉结构，直观体现会话的来源渠道与处理该会话的机器人身份。

#### Scenario: 列表项视觉校验
- **WHEN** 用户查看会话列表
- **THEN** 每个列表项呈现明显的来源品牌色标识，且不丢失机器人标识
