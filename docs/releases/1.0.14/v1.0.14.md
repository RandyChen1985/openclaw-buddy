## 🚀 新增特性 (New Features)

### 1. AI 实时交互画布与物理隔离沙箱 (Interactive Artifact Canvas / IAC) 🖼️

* **IAC 互动舞台**：升级在线聊天页面，实装全新的**实时交互式画布 (IAC)**。AI 生成的 HTML、SVG 页面可在独立的右侧画布中沙箱渲染，实现物理隔离，有效防范宿主页面 DOM 注入与安全污染。

- **文件多标签页浏览器 (Multi-Tab)**：画布集成精美的文件管理器，支持文本、图片、PDF 等多种主流媒体的直接预览展示，并支持 Tab 多标签页流畅切换，交互动效极为自然。
- **双轨自愈重绘机制**：针对画布关闭无效、关闭后无法二次点击唤醒的业界通病，首创**双轨 Ref 映射与 `forceReset` 强制重绘自愈机制**，彻底解决生命周期闭环上的边界缺陷。

* **💡 大白话：** 以后 AI 生成的代码、原型、设计稿或者大文件，都在右侧宽阔的专属“沙箱画布”里流畅看、顺手玩，聊天气泡再也不会被超长代码给撑爆了。

### 2. 私有技能全生命流转生态：克隆共享、会话提炼与聊天拖拽唤醒 📡

* **一键会话提炼生成**：借鉴 `skill-creator` 最佳实践，支持在对话过程中直接一键将聊天会话提炼并智能生成新的私有技能，实现开箱即用的“会话 ➔ 技能”敏捷开发闭环。

- **聊天 `@` 提及唤醒**：精美打磨提及 (Mention) 选择器交互逻辑，输入 `@` 时能够快速实时过滤、精准匹配并智能唤醒所需的可用技能。
- **物理拖放拖入对话**：支持在可用技能抽屉中直接双击或“物理拖拽”技能卡片至聊天输入框中，秒级生成快捷指令和应用占位，操作极其自然。
- **跨 Bot 共享克隆与后缀隔离**：私有卡片右侧新增 `Share2` 图标与磨砂面板，物理层安全克隆复制技能目录。自动为目标 Bot 写入的配置追加 `_[toBotID]` 后缀，Go 后端自动扫描解析并改写 `plugin.json`、`skill.yaml` 和 `SKILL.md` 的 `name` 属性，规避同名冲突。
- **磁盘扫描兜底与热重载**：打破 CLI 单工作区硬编码限制，加入 Go 后端动态物理磁盘遍历与 `mtime` 精准解析作为兜底，实现高容错热同步与秒级热重载。

* **💡 大白话：** 现在，私有技能的生命周期完全打通了：聊着天能一键炼出技能，想用时在输入框敲个 `@` 或把技能卡片直接拖进对话框就能用，还能随手跨智能体一键共享且自动隔离重名冲突，底层还有物理磁盘扫描兜底，技能流转体验直接飞起！

### 3. 右侧面板一键关闭、Dock 多列布局与提到附件拖拽 🛰️

* **侧边栏菜单层级**：侧边栏菜单顺序重构，将“智能体中心”（原“资产管理”）上移至“监控中心”前，产品业务脉络更加清晰。

- **一键关闭与多列 Dock**：统一右侧各子面板关闭按钮至拖拽标题栏右侧，移除冗余关闭按钮，进一步调大叉号尺寸并提升视觉对比度；支持一键关闭及多列 Dock 弹性布局展示。
- **拖拽附件与提及**：支持将文件管理器中的文件直接拖入输入区，自动识别并生成 `@附件` 引用。
- **终端选区发送 AI**：运维终端支持选区选中文本一键快捷发给 AI 助手，且支持 Ignore 配置文件过滤本地状态。

* **💡 大白话：** 界面排布随心调，文件拖拽就能发送，甚至在运维终端看到异常信息，鼠标一划就能直接甩给 AI 诊断，简直是运维神器。

### 4. 前端 UI/UX 顶级精装方案落地 ✨

* **输入区太空舱**：集成极光渐变发送按钮、拖拽上传太空舱、聚焦呼吸环及毛玻璃 Plus 主菜单，视觉质感直接拉满。

- **会话列表极奢微动效**：实装高雅的流光骨架屏（Shimmer Skeleton）、极细悬浮阻尼滚动条，配合弹性物理动力学过渡，长列表拉动顺滑无阻。
- **思考占位药丸与极致避让**：
  - 开启显示思考：多重脏省略号深度滤除，实现首字未出到正在思考占位文案的无缝动态接力，自适应智能追加工具轮次提示；
  - 关闭显示思考：将已完成态重构为翠绿色打勾的极简系统注脚，等待提示变更为“请稍后...”，工具调用单位由 '个工具' 统一为 '轮工具'；
  - 药丸胶囊微动效：精装折叠思考链为高对比度精致胶囊卡片，引入双重物理嵌套呼吸特效与 6 点水波纹打字跳动动画。
- **卡片悬浮拉伸避让**：技能卡片在 Hover 时通过 CSS cubic-bezier 曲线平滑右拉内边距（32px ➔ 48px ~ 108px），为复制、共享、重载等悬浮工具组预留完美避让空间，无 hover 时空间平滑收回。

* **💡 大白话：** 从输入区、列表滚动条到 AI 的思考过程药丸，我们把所有的像素边缘和微小的动画都磨平、精装了一遍。

## 🛠️ 稳定性、修复与安全加固 (Fixes & Chores)

### 1. 四大核心安全防护与自愈 🔒

* **防止 OS 命令注入**：彻底重构 `IsProcessRunning` 等底层进程判定逻辑，采用参数安全隔离的 API，彻底杜绝 Shell 级别命令注入攻击。

- **标准契约对齐**：全面重构 `ansiStrippingWriter` 契约适配标准库逻辑，保证终端日志字符转义层物理合规。
- **Hosts 多重自愈**：修复自愈验收中物理宿主机 `hosts` 动态挂载与回填的多重适配冲突。
- **审计丢失尾行修复**：修复审计数据采集器对尾行 EOF 丢失造成的数据丢失漏记 Bug，确保数据收集 100% 完整。

### 2. 交互与性能深度调优 🧩

* **优化 ECharts 在 AI 消息流式输出（Streaming）下的重绘抖动**：打字过程中静默挂起 `animation` 并配合增量合并与指纹序列化缓存去重对比，彻底消除流式打字中图表频繁刷新与反复长出柱子带来的重绘抖动闪烁。

- **终端智能滚动锁定**：终端输出（:::commandOutput）引入滚动锁定与随流置底机制，并贴心提供终端内容一键复制浮标。
- **历史消息一键重试与排队**：实现历史消息终端一键再次执行卡片，以及防多任务资源死锁的自适应排队并发调度机。
- **模型试聊精简**：模型试聊 Drawer 输入框内嵌发送按钮，轮询统一重构为高能效的 20 秒，支持直连厂商 API 提升流式反馈效率。
- **运维终端连接泄露修复**：彻底修复运维终端长时间开辟导致的连接泄露，并对拖拽列宽进行 rAF (requestAnimationFrame) 节流性能加固，拒绝抖动与顿挫。
- **Markdown 导出 100% 对齐**：顶栏一键导出 Markdown，导出的文本内容与聊天区可见内容格式、块级别排版达成完美 100% 对齐。
