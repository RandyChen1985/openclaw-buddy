🚀 NEW FEATURES

01 全局视觉审美统一：深邃暗黑之美 🎨
美，是不分角落的。我们对 Web 端进行了全方位的审美重塑，确保每一个像素都流淌着统一的设计语言。
• 全场景暗色补齐: 彻底补齐了 Web 全局暗色模式，确保与 Chat V3 的沉浸式体验完全一致。
• 品牌与菜单和谐: 统一了侧边栏品牌区与子菜单的样式，消除了视觉上的割裂感。
• 环境标签重塑: 运行状态的环境 Tag 样式统一且常驻于状态条，侧栏不再显示冗余信息。

💡 大白话：现在整个网页的暗黑模式都对齐了，看着更高级。侧边栏没用的标签藏起来了，放到了底部的状态条里，移动端看着也整齐多了。

02 随心而动的交互空间：灵动布局 3.0 🗄️
我们将控制权彻底交还给用户。现在，你的工作区不再是固定的格子，而是可以呼吸的灵感画布。
• 窗口自由迁徙: 文件浏览器与终端窗口现在支持全量拖动移位，打造最顺手的 IDE 布局。
• 布局深度联动: 解决了 Mention 弹窗闪动问题及终端/文件浏览器全屏切换后的位置偏移。
• 编辑效率补完: 文件编辑器右下角新增「复制全部内容」悬浮按钮，代码搬运一瞬之间。

💡 大白话：现在的弹窗和窗口可以随便拖来拖去了。以前那个点名（Mention）弹窗闪烁的问题也修好了。编辑器里还加了个“一键复制全部”的按钮。

03 无国界沟通：70+ 词条全量补全 🌐
我们相信，好的工具不应该有语言的隔阂。
• 英文词条大爆发: 全量补齐了 70 多个缺失的英文词条，覆盖设置到复杂交互的每个角落。
• 测试驱动质量: 同步更新了自动化测试清单，确保国际化质量的长治久安。

💡 大白话：我们把之前漏掉的英文翻译全给补上了，足足 70 多个地方。现在用英文版也不会看到莫名其妙的中文了。

🛠️ STABILITY & OPTIMIZATIONS

1. 逻辑与渲染优化 ⚡

• 消息过滤精度: 修复 visibleMessages 依赖缺失问题，解决流式输出时的过滤错误。
• 状态同步优化: 通过忽略特定相位，避免了高并发操作下的误锁/释锁问题。

2. 系统自愈与健壮性 🛡️

• Guardian 自愈增强: 新增避让逻辑，智能避让诊断进程及 npm 安装过程。
• 文档与元数据修复: 修复 README 徽章链接，确保项目门面真实可信。
