## 🚀 新增特性 (New Features)

### 1. 专家市场与画像注入 (Expert Market & Injection)
*   **专家生态**: 现已集成“专家市场”模块，支持从数十位预设专家（技术、文案、法务等）一键创建对应的机器人。
*   **画像规范化**: 修正了 `SOUL.md` 与 `IDENTITY.md` 的写入逻辑，完美对齐 OpenClaw CLI 的路径规范与全大写命名协议。
*   **一键克隆**: 支持在创建时动态选择模型，自动化生成 Bot 独立的 `workspace` 与环境配置。

### 2. 沉浸式终端与运维控制 (Dual-Terminal Ops)
*   **沉浸式 TUI 聊天**: 将 OpenClaw 原生 TUI 深度集成，提供全屏对话体验。支持全屏悬浮控制组及自动聚焦。
*   **Web 运维终端优化**: 仪表盘底层的“实时日志”与“命令终端”现已支持全屏铺满显示。修复了移动端下虚拟键盘遮挡输入行的问题，极大提升了远程运维的便携性。
*   **通信稳定性**: 修复了 WebSocket 在处理特定二进制大对象时的编码错误，确保极速日志滚动且不丢包。

### 3. 系统级安全与运营 (Core Ops & Security)
*   **安全锁死机制 (Lockdown Mode)**: 新增环境监控联动的安全锁死逻辑，当核心组件检测到配置风险或外部入侵时，系统将自动挂起高危端口，保护数据安全。
*   **渠道与模型同步**: 渠道管理现已支持在线编辑，且成功连接后会自动同步全量模型至“默认组”，大幅降低运维心智负担。

---

## 🎨 WOW Effect 视觉增强

*   **卡片底色回归**: 修复了机器人卡片与模型卡片的“美颜”功能。现在卡片会根据索引自动应用绚丽的淡彩色渐变底色。
*   **Emoji 动态图标**: “虾兵蟹将”管理页面现已支持动态显示机器人自带的 Emoji 标识。
*   **3D 悬浮特效**: 所有的 Bot 和模型卡片均引入了 `card-float` 类动效，鼠标悬停时会伴随柔和的阴影及上浮反馈。

---

## 🛠️ 性能修复 (Bug Fixes)

*   **环境监控重构**: 仪表盘底层的环境监控逻辑进行了重构，提高了数据的采样精度与安全性。
*   **WebSocket 权限容错**: 增强了 TUI 模式下的权限验证与 Token 刷新逻辑。
*   **沉浸式面板提取 (Drawer UI)**: 深度优化了移动端与 Web 端的“侧边栏面板提取”交互，支持平滑的手势划出与一键沉浸。
*   **布局精修**: 优化了 Dashboard 在平板设备下的显示宽度，解决了表格溢出的遗留问题。
