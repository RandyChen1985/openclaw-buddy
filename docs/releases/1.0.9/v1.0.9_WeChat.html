🚀 NEW FEATURES

01 Bot 工作区 2.0 📂
• 核心配置可视化: 直接编辑 agent.md (行为定义) 与 heartbeat.md (心跳逻辑)，实时调整 Bot 的底层性格与运行节律。
• 全功能文件管理: 支持文件的上传、下载、在线编辑与删除。配合 Markdown 实时预览，无论是知识库文档还是临时生成的日志，尽在掌握。

💡 大白话：现在你可以直接钻进机器人的“脑子里”改它的说明书了。想要给它传文件，或者把它写的东西下到本地，点点鼠标就能搞定。

02 全渠道联动 🌍
• 多平台对齐: 现已完美集成 飞书 (Feishu/Lark)、Telegram 与 QQBot。
• 一键绑定逻辑: 优化了渠道绑定的 UI 交互，支持多账号并行管理，大幅降低了各平台 Token 与 Webhook 的配置门槛。

💡 大白话：现在你可以把 Buddy 连到飞书、Telegram 甚至 QQ 群里了。不管你在哪，Buddy 都能随时待命，多平台消息同步收发。

03 审计大屏 📊
• 实时数据洞察: 基于 ECharts 构建的动态图表，全天候监控 Token 消耗趋势、Agent 分布、模型覆盖度及工具调用频率。
• 安全合规追踪: 独立的审计日志系统，实时追踪高风险指令与异常调用，支持关键词搜索与风险等级过滤。

💡 大白话：出个“监控大屏幕”，一眼就能看到机器人今天花了多少钱、哪个机器人最忙、系统累不累。

04 Chat V3 沉浸式优化 🎮
• 沉浸式全屏模式: 支持快速进入全屏，配合精心设计的胶囊顶栏，让灵感不再受杂乱信息的干扰。
• 手术级性能调优: 并发化加载流程，移除 300ms 延迟，首屏加载速度提升 50% 以上。
• 智能停顿感知: 优化了 Stall Timer 逻辑，仅在文字流（Delta）真正停顿且非元数据更新时触发安抚文案，让“AI 还在思考”的提示更精准。
• WebSocket 实时调试: 内置 WS 日志面板，实时监控底层协议流，针对深色模式进行了可见度专项优化。

💡 大白话：聊天界面能全屏了，而且响应速度变得飞快，几乎秒开。顶部的标签变漂亮了，还加了个“调试模式”，高手查问题时更方便。

🛠️ STABILITY & OPTIMIZATIONS

1. 性能与并发 ⚡

• 首屏加载飞跃: 并发拉取 Ticket/Token，移除人为 300ms 延迟缓冲，响应几乎毫秒级。
• 并行事务追踪: 引入 activeRuns 机制，实现复杂 Agent 任务并行追踪，修复思考状态早释 Bug。
• 高效轮询机制: 优化全局状态轮询，大幅降低前端对后端的无效请求频率。

2. 协议与交互 🛡️

• 权威状态同步: 基于 sessions.changed 1:1 同步网关状态，彻底解决输入框“打字锁”残留与闪烁。
• 智能停顿算法: 精构 Stall Timer，排除元数据干扰，确保“安抚文案”触发恰到好处。
• 延时释锁优化: 优化 lifecycle.end 与 chat.final 竞争逻辑，确保网络波动下正确释锁。

3. UI/UX 精细化 🎨

• 顶栏胶囊化设计: 采用 999px 全圆角胶囊设计，并增加灵动 Hover 变色反馈。
• 编辑体验增强: 引入 Token 实时估算浮标；修复灵魂编辑器预览 Markdown 渲染冲突。
• 响应式适配: 修复侧边栏折叠名称消失 Bug；优化机器人卡片与记忆编辑器布局。

4. 后端与系统健壮性 🏗️

• 路径自动展开: 修复处理带波浪号 (~) 路径的 500 错误，实现主目录安全识别展开。
• 执行超时优化: 调优后端指令超时阈值，完美适配重型插件加载，杜绝 Context 超时报错。
• 配置持久化修复: 确保渠道配置精准写入隔离环境目录，并增强物理文件删除校验。
