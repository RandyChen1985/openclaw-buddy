OpenClaw Buddy

v1.0.4 发布。

疾速的回响，安全的重塑。

“有人说，速度是一场关于遗忘的竞赛。我在 18789 端口的深处，听见了 WebSocket V3 的第一次回响... 当你按下回车的那一瞬间，你会听见，这个世界正以更快的方式向你走来。”

在线聊天 V3。毫秒级。

全量接入 WebSocket V3 协议。不仅是消息，连思考状态与元数据均实现流式同步。支持多端实时状态对账。

💡 大白话：以前聊天像发邮件，回一下等一下。现在像面对面说话，你刚打完字，所有终端都同步了，主打一个“快”和“准”。

认证模块。安全性重塑。

引入 Ticket 票据机制与多实例存储空间隔离。彻底解决了 Token 泄露与多实例数据冲突的潜在风险。

💡 大白话：以前你的“通行证”可能会被人窥见，现在换成了阅后即焚的任务密电。而且即便你开了好几个窗口，它们也不会再搞混。

Windows 支持。基础架构。

建立了基于 Wails 的 Windows 编译流，初步实现了窗口初始化与系统托盘骨架。

💡 大白话：虽然 Windows 版的影子已经出现了，但它还在“练习生”阶段。目前仅具备基础架构，更多黑科技还在紧张调试中。

全量修复。稳定性加固。

清理了 30 余项已知 Bug，涵盖备份 Diff 对比、一键自动更新机制以及 UI 锁定释放优化。

细节改进与修复。

  • 备份 Diff 引擎：支持源码预览与历史差异比对。
  • API 保护：为 chatProxy 增加了 3 分钟强制超时机制。
  • UI 打磨：修复 ChatV3 模拟光标位置，优化 i18n 翻译。
