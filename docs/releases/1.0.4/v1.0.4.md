## 🚀 核心更新 (Key Features)

### 1. 在线聊天 V3: 毫秒级双模体验 (WebSocket V3 Mode)

* **极速响应**: 全量接入 WebSocket V3 协议。不仅是消息，连思考状态与元数据均实现流式同步。
* **多端实时同步**: 基于 Derived Device ID 机制，你在桌面端发送的消息，移动端将实现瞬时状态对账。
* **💡 大白话：** 以前聊天像发邮件，回一下等一下。现在像面对面说话，你刚打完字，所有终端都同步了，主打一个“快”和“准”。

### 2. 认证模块重塑: 工业级安全屏障 (Hardened Security)

* **Ticket 票据机制**: 引入了一次性授权票据（Ticket），彻底解决了 Token 在 URL 或 WebSocket 连接中明文暴露的风险。
* **多实例存储隔离**: 实现了基于运行路径的 `LocalStorage` 物理隔离，确保同一域名下不同实例的配置数据互不干扰。
* **💡 大白话：** 以前你的“通行证”可能会在路上被人窥见，现在我们换成了阅后即焚的任务密电。而且就算你开了好几个 Buddy 窗口，它们也不会再搞混。

### 3. Windows GUI 基础架构 (Experimental Windows Foundation)

* **Wails 架构初步接入**: 建立了基于 Wails 的 Windows 编译流，初步实现了 WebView2 窗口初始化与系统托盘骨架。
* **PTY 调试中**: 目前已完成 Windows 版 PTY 终端的基础调用逻辑，仍在针对复杂字符集渲染与权限控制进行深度调试。
* **💡 大白话：** 虽然 Windows 版的影子已经出现了，但它还在“练习生”阶段。目前仅具备基础架构，更多黑科技还在紧张调试中。

### 4. 工业级自动升级与自修复 (Self-healing & Update)

* **一键云端升级**: 实现了后台自动比对、静默下载与版本热更替。
* **智能避让机制**: 在用户操作或系统自愈期间，升级进程会自动排队，防止环境冲突。

---

## 🛠️ 稳定性与 Bug 全量修复 (Extensive Bug Fixes)

* **已知 Bug 大量清理**: 深度清理了自 v1.0.3 发布以来反馈的 30 余项稳定性和交互 Bug，涵盖了从数据解析异常到前端渲染抖动的全量回归。
* **备份历史查看**: 增加了备份文件的源码预览与 Diff 差异对比，配置变更的历史痕迹清晰可查。
* **重复操作锁定修复**: 彻底解决了插件管理与技能同步页面的按钮重复点击问题，引入了精确的数据对账锁。
* **API 超时保护**: 为 `chatProxy` 增加了 3 分钟的底层强制超时保护，杜绝僵尸连接占用服务器资源。
* **i18n 全量对齐**: 修复了监控中心任务名称、占位符及删除确认框中可能出现的 Key 未定义问题。
