🚀 NEW FEATURES

01 多模态视界 2.0：从“看见”到“洞察” 👁️
Buddy 对世界的感知不再局限于文字。现在，它是你处理复杂多模态任务的最佳搭档。
• 图片粘贴与分析: 支持聊天框直接粘贴图片，自动触发多模态视觉模型深度解析。
• 强制语言对齐: 全量优化分析指令，强制 AI 使用中文回复，确保沟通无碍。
• 多维预览矩阵: Word、Excel、PDF、Image 直接在线预览，无需下载。

💡 大白话：截图直接往聊天框一贴就能问，它看得更清楚了，而且一定会用中文回你。想看文件夹里的文档或图片，直接点一下就能预览。

02 Bot 工作区 3.0：AI 驱动的沉浸式协同工坊 🛠️
不再只是冰冷的文件管理器。我们将 Cursor 级的 IDE 交互体验 搬进了 Buddy 的聊天流，让“对话”即“工作”。
• 智能上下文唤起 (@Mention): 支持在聊天中使用 @ 语法直接引用文件、文件夹或 Skills 资源。AI 将瞬间理解你的项目脉络，提供更具针对性的建议。
• 灵感即时固化: 聊天中生成的任何代码、文档或配置，配合全新的悬浮保存按钮，可一键同步至 Bot 工作区。
• 命令行深度共生 (CLI): 无需离开对话界面，即可一键唤起终端执行指令。配合文件树的右键管理功能，实现从调试到部署的全流程闭环。

💡 大白话：现在你可以在聊天里用 @ 像点名一样引用文件夹或技能，机器人就像你的同事一样懂你的项目。AI 写出的好东西点一下就能存进它的“脑子里”，还能直接弹窗跑命令行，效率直接拉满。

03 全平台交互打磨：每一个像素都有温度 🎨
我们重新审视了每一个 UI 细节，确保在不同终端下都能提供一致的尊贵体验。
• 会话 ID 全量展示: 在 Web 端不再隐藏或缩略会话 ID，支持完整显示与一键复制，方便开发者进行精准调试。
• 智能分组过滤: 会话列表现在支持按 Bot 和渠道进行双重过滤分组，即使管理上百个会话也能井然有序。
• 移动端布局重塑: 针对移动端进行了专项优化，将搜索框上移至标题栏，大幅提升了小屏幕下的内容展示空间。
• 反馈生态闭环: 侧边栏与概览页新增“反馈邮箱”图标，一键唤起邮件客户端或复制反馈地址。

💡 大白话：手机上用起来更宽敞了，找对话可以按机器人分类。如果你觉得哪里不好用，点一下旁边的信封图标就能给我们发邮件。

🛠️ STABILITY & OPTIMIZATIONS

1. 性能“脱胎换骨” ⚡

• 上传性能爆发: 优化附件上传链路，彻底解决大文件 504 挂起问题。
• 思考计时同步: 引入时间戳机制，修复流式更新时思考计时器重置 Bug。
• 引用清洗逻辑: 自动清洗引用消息中的冗余元数据，回复更清爽。

2. 协议与容错 🛡️

• ECharts 容错: 增强渲染容错，自动修复带 JS 前缀或未闭合括号的配置。
• 超长指令适配: 指令超时大幅增加（扫码延至 90s），适配重型插件需求。
• 剪贴板后备: 针对非安全上下文添加后备方案，复制操作更可靠。

3. 细节修复清单 🔧

• 样式隔离: 修复文件夹浏览器导致的全局 Markdown 样式污染。
• 对齐修复: 修复文件浏览器侧边栏图标与名称微小的像素偏移。
• 状态同步: 优化 Dashboard 初始显示，增加灰色“连接中”状态。
