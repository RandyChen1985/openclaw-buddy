🚀 NEW FEATURES

01 ChatV3 视觉与逻辑重构 🎭
🖼️ [此处插入 ChatV3 渠道可视化插图]
• 渠道可视化: 会话列表支持识别飞书、微信、Telegram 及 Cron 图标。
• 状态指示灯: 新增生成状态实时反馈，非当前会话显示“脉冲”动画。
• 多维主题系统: 引入“雅致灰”等主题模式，搭配彩色设置按钮。
• 思考过程深度定制: 支持手动开关思考流并提供分级调节能力。
💡 大白话：现在你的聊天列表更清晰了，哪些是机器人发的，哪些是定时任务干的一目了然。AI 正在别处想问题时，侧边栏会有个小灯在闪。而且，如果你嫌 AI 太啰嗦，现在可以直接关掉它的“碎碎念”，或者让它想深一点。
02 自愈管理系统 🏥
🖼️ [此处插入自愈管理“随身医生”插图]
• 在线配置编辑器: 直接在 Web 端安全编辑 openclaw.json，支持高亮与校验。
• Doctor 一键修复: 集成 openclaw doctor，自动识别并指引修复漏洞或依赖丢失。
💡 大白话：以后配置搞乱了不用怕，也不用去翻服务器改文件。直接在网页里改配置，或者点一下“医生”按钮，系统会自动检查哪儿坏了并帮你修好。
03 指令并行化架构 ⚡
🖼️ [此处插入并行化“快且独立”插图]
• 并行执行引擎: 所有 OpenClaw 指令调用改为并行执行，告别单线程阻塞。
• 网关状态解耦: 即使在网关离线状态下，核心管理指令依然能精准触达。
💡 大白话：以前 Buddy 像是一个窗口只能排队办事，现在变成了多个窗口同时开工。而且不管“大门”（网关）开没开，你都能在后台直接点名指挥 AI 兵团。
STABILITY_PATCH_v1.0.7
🛠️ 解析鲁棒性: 彻底重塑 Agent 与 Model 的解析逻辑，物理隔离干扰，杜绝报错。
🛠️ 消息时序加固: 修复了 V3 模式切换会话时的消息渲染漏洞，确保对话流的时间线性。
🛠️ 标题生成防御: 优化自动标题触发机制，彻底解决标题重复重叠的 Bug。
🛠️ 配置校验沙箱: 增加详细反馈，防止无效环境变量导致配置丢失。
🛠️ 视觉细节补丁: 修复 JSON 编辑器光标由于内边距导致的不对齐及移动端溢出。
