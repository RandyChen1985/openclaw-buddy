EXHIBITION // 04.19

OpenClaw Buddy v1.0.8.

灵动之脑，节律之美。

🖼️ EXHIBIT: v1.0.8 MAIN BANNER

“在智能的交响乐中，每一个字节都是跳动的音符。如果说 1.0.7 是在重塑骨骼，那么 1.0.8 则是在赋予 Buddy 更加灵动的‘思考’与‘节律’。”

本次版本，我用 Claude 模型对系统进行了深度重构。这不仅仅是代码的重写，更是一次灵魂的对齐。我们将 V3 聊天接口与 OpenClaw 源码进行了底层联调，让每一个审批、每一份回执都能精准触达；我们优化了 AI 的思考展示，让逻辑的流动清晰可见；我们新增了定时任务管理，让自动化的齿轮按照既定的节律完美运转。

秩序与灵动，在此刻共鸣。

New Exploration // 核心特性

Claude 深度重构

• 架构解耦: 进一步优化了内部逻辑层与表现层的分离，极大提升了系统的响应速度与可维护性。
• 代码健壮性: 在 Claude 的协助下，修复了多处潜在的边缘案例 Bug，系统运行更加稳如磐石。

💡 大白话：我们花了大钱请 Claude 老师帮 Buddy 的家底彻底翻修了一遍。现在的 Buddy 不仅反应更快，而且底子更厚，不容易出莫名其妙的小脾气。

V3 协议完美对齐

• 全量事件支持: 不再局限于纯文本。现在 V3 接口完整支持包括 审批 (Approval)、回执 (Receipt) 等在内的各种复杂事件消息。
• 直连消息源驱动: 新增 Buddy 平台专属消息源标识，让消息的来源追溯更加精准。
• 网关 Token 预取: 针对网关 Token 预取逻辑进行优化，显著降低首条消息延迟。

💡 大白话：现在 Buddy 说的话、办的事跟 OpenClaw 原版完全对齐了。不管你是要审批还是发回执，Buddy 都能听得懂、做得到，而且发消息比以前更快了。

思考展示 2.0

• 增强型元数据折叠条: 更加雅致的 UI 设计，将思考过程、工具调用与命令输出完美融合在消息气泡中。
• 流式停顿感知: 新增「思考中」动画与旋转图标。当 AI 在逻辑深处沉思时，界面会动态告知其状态，杜绝由于生成卡顿带来的误解。
• 终端样式输出: AI 执行的系统命令现在以专业的终端样式呈现，支持即时折叠，还原真实的技术场景。

💡 大白话：现在 AI 思考问题时会转圈圈提示你它在想，不会让你觉得界面卡住了。它的思考过程、调用的工具都藏在漂亮的小折叠条里，想看就点，不看就收起来，清爽干净。

定时任务 (Cron) 管理

• 可视化调度中心: 新增独立的定时任务页面，支持一键查看、编辑与监控所有自动化任务的运行状态。
• 排版与可用性优化: 针对任务列表进行了深度排版优化，关键水位线与用量提示一目了然。

💡 大白话：以后想看机器人什么时候干活、任务跑得怎么样，直接去新出的“定时任务”页面就行了。所有的计划都在你眼皮底下，想改就改。

Stability & Fixes // 稳定性
[FIX] CPU 占用优化: 修复了 Classic 聊天模式下，流式结束路径不闭合导致浏览器 rAF 持续空转、占满 CPU 的严重故障。
[FIX] UI 状态残留修复: 彻底解决了会话侧边栏「正在输入」图标在消息结束后仍不消失的问题，并优化了新会话创建时的输入锁定逻辑。
[FIX] 防连点与即时响应: 优化了首条消息发送逻辑，支持新会话即时创建，并增加了全局防连点机制。
[FIX] 消息时序加固: 持续优化 WS 协议下的消息排序，修复了由于极端网络抖动可能引起的重复气泡显示。
[FIX] JSON 提取增强: 进一步增强了插件输出中 JSON 内容的提取健壮性，即使内容中夹杂无关字符也能精准识别。
