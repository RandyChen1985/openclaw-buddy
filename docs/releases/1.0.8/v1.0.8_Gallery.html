EXHIBITION // 04.19

OpenClaw Buddy v1.0.8.

灵动之脑，节律之美。

🖼️ EXHIBIT: v1.0.8 MAIN BANNER

“在智能的交响乐中，每一个字节都是跳动的音符。如果说 1.0.7 是在重塑骨骼，那么 1.0.8 则是在赋予 Buddy 更加灵动的‘思考’与‘节律’。”

本次版本，我用 Claude 模型对系统进行了深度重构。这不仅仅是代码的重写，更是一次灵魂的对齐。我们将 V3 聊天接口与 OpenClaw 源码进行了底层联调，让每一个审批、每一份回执都能精准触达；我们优化了 AI 的思考展示，让逻辑的流动清晰可见；我们新增了定时任务管理，让自动化的齿轮按照既定的节律完美运转。

秩序与灵动，在此刻共鸣。

New Exploration // 核心特性

Claude 深度重构

进一步优化内部逻辑层与表现层的分离，极大提升响应速度；修复多处潜在边缘案例 Bug，系统运行稳如磐石。

💡 大白话：我们花了大钱请 Claude 老师帮 Buddy 的家底彻底翻修了一遍。现在的 Buddy 不不仅反应更快，而且底子更厚。

V3 协议完美对齐

ChatV3 现已完成与源码底层的对齐。完整支持审批、回执等复杂事件；新增 Buddy 专属消息源标识，优化鉴权流程降低延迟。

💡 大白话：现在 Buddy 说的话、办的事跟 OpenClaw 原版完全对齐了。不管发审批还是回执，Buddy 都能听得懂、做得到。

思考展示 2.0

更加清晰的元数据折叠条，融合思考、工具与命令输出。新增「思考中」动画与专业终端样式呈现，支持即时折叠。

💡 大白话：现在 AI 思考问题时会转圈圈提示你它在想，不会让你觉得界面卡住了。它的思考细节都藏在漂亮的小折叠条里。

定时任务 (Cron) 管理

新增可视化调度中心页面，支持一键查看、编辑与监控自动化任务；优化排版，关键水位线提示一目了然。

💡 大白话：以后想看机器人什么时候干活，直接去新出的“定时任务”页面就行了。所有的计划都在你眼皮底下。

Stability & Fixes // 稳定性
[FIX] CPU 占用优化: 修复 Classic 模式流式结束漏洞导致的 CPU 满载故障。
[FIX] UI 状态残留: 彻底解决「正在输入」图标残留，优化新会话输入锁定。
[FIX] 即时响应: 优化首条消息逻辑，支持即时创建与全局防连点机制。
[FIX] 消息时序: 调优 WS 协议消息排序，修复由于网络抖动引发的重复气泡。
[FIX] JSON 增强: 提升插件输出中 JSON 内容提取的健壮性，确保精准识别。
