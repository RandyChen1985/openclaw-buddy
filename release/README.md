# 🦞 OpenClaw Buddy - 专业级 AI Agent 监控与自愈伴侣

**OpenClaw Buddy** 是一款专为 **OpenClaw (小龙虾 AI Agent)** 打造的带外管理 (Out-of-band Management) 与自愈系统。它作为独立运行的“监控哨兵”，确保您的 AI 代理在任何情况下都能稳定在线。

---

## ✨ 核心价值 (为什么选择 Buddy?)

1.  **🛡️ 独立哨兵 (OOB)**：即使 OpenClaw 主进程由于配置错误、插件冲突或内存溢出崩溃，Buddy 仍能独立运行并将其拉起。
2.  **⚡ 极速登录体验**：独家支持微信插件流式二维码捕获。无需翻阅冗长的系统日志，直接在 Web 界面扫码登录，秒级完成授权。
3.  **🩺 智能自动化自愈**：实时监测 OpenClaw 指标。一旦发现响应延迟过高或进程僵死，自动执行配置回滚与服务重启，将故障时间缩短至秒级。
4.  **📊 全维度可视化看板**：实时追踪 CPU、内存占用、API 响应时间及系统日志。
5.  **🤖 资产透明管理**：直观管理所有机器人 (Bots) 与模型提供商 (Providers)，支持在线修改机器人身份与模型映射。
6.  **🔔 交互式预警**：支持飞书机器人通知，故障告警与登录提醒直接推送到手机，并支持在飞书卡片中直接操作。

---

## 🚀 快速启动

### 1. 准备环境
确保您的服务器满足以下条件：
- Linux (x86_64) 或 macOS 环境。
- 已安装并配置好 **OpenClaw**。

### 2. 配置参数
编辑目录下的 `env` 文件（首次运行前请务必确认）：

```env
# 面板监听端口
WEB_PORT=3000

# 访问安全令牌 (非常重要！建议修改为复杂的字符串)
# 首次运行会自动生成一个随机令牌，您也可以手动指定
BUDDY_TOKEN="sk-your-secure-token"

# OpenClaw 配置目录 (通常为 ~/.openclaw)
OPENCLAW_CONFIG_DIR="~/.openclaw"

# 飞书通知 (可选)
FEISHU_ENABLED=false
```

### 3. 一键启停
使用配套的脚本管理服务：

- **启动**: `bash start.sh` (服务将后台运行，并自动追踪前 20 行日志)
- **停止**: `bash stop.sh`
- **查看日志**: `tail -f logs/guardian.log`

---

## 📂 目录结构说明

- `lib/openclaw-buddy`: 核心压缩编译的二进制执行文件。
- `logs/`: 存放系统运行日志。
- `data/`: 存放 SQLite 数据库（巡检记录、自愈事件）。
- `backups/`: 自动备份的 OpenClaw 配置快照。
- `reports/`: 定期生成的巡检报表。
- `env`: 核心环境配置文件。

---

## 🛡️ 安全建议
- 请开启防火墙，仅开放 `WEB_PORT` (默认 3000) 给受信任的 IP。
- 强烈建议修改默认的 `BUDDY_TOKEN`。
- 如果在公网使用，建议在前面加一层 Nginx 并配置 SSL 证书。
